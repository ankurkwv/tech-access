# Tech Access

Prepare invitations and email through a connected account. Email is sent manually.

## Install

1. In the desktop client's plugin directory, add `https://github.com/ankurkwv/tech-access.git` as a marketplace. Leave the Git ref and sparse paths empty.
2. Open **Personal**, select **Tech Access**, install it, and connect the required app if prompted.
3. Ask: “List the available inviters.”

Git marketplaces added on your computer appear under **Personal**. This repository is public; its position in the plugin directory does not change that.

The connected service uses your signed-in identity and existing permissions. Installing this package does not grant access to the service.
